# ⏱️ Time Series Analysis Notes

This repository contains a comprehensive set of notes on **Time Series Analysis**, ideal for data scientists, analysts, and machine learning enthusiasts. Whether you're preparing for interviews, working on forecasting projects, or just looking to solidify your concepts—these notes will be your go-to guide.

## 📚 What's Inside

These notes cover all the essential and advanced topics in time series, including:

### 🔹 Core Concepts
- Time Dependency
- Trend & Seasonality
- Cyclic Behavior
- Stationarity & Noise
- Autocorrelation & Granularity

### 🔹 Data Preparation
- Handling Missing Values
- Outlier Detection
- Resampling
- Feature Engineering

### 🔹 Decomposition & Transformation
- Additive & Multiplicative Models
- STL Decomposition
- Log, Power, Box-Cox Transformation

### 🔹 Forecasting Models
- AR, MA, ARMA, ARIMA
- SARIMA, SARIMAX
- VAR, VARMA, VARIMA
- GARCH
- Facebook Prophet

### 🔹 Smoothing Techniques
- SMA, WMA, EMA
- Exponential Smoothing (SES, DES, TES)

### 🔹 Model Selection & Evaluation
- AIC, BIC
- Residual Analysis, Ljung-Box, ACF/PACF
- MAE, MSE, RMSE, MAPE
